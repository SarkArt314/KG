# Лабораторная работа 3. Базовые растровые алгоритмы

Программа демонстрирует четыре базовых растровых алгоритма:

1. Пошаговый алгоритм построения отрезка.
2. Алгоритм ЦДА.
3. Алгоритм Брезенхема для отрезка.
4. Алгоритм Брезенхема для окружности.

## Возможности

- Построение выбранного алгоритма по заданным целым или дробным координатам.
- Масштабирование:
  - кнопками `+`, `-`, `Сброс`;
  - колесом мыши.
- Перемещение по сцене левой кнопкой мыши.
- Отображение:
  - системы координат;
  - осей X и Y;
  - линий сетки;
  - подписей координат.
- Замер времени выполнения алгоритма.
- Бенчмарк всех четырёх алгоритмов.

## Запуск

```bash
python main.py
```

или:

```bash
python -m raster_lab
```

## Сборка exe

Для сборки под Windows:

```bat
build.bat
```

После сборки исполняемый файл появится в папке `dist`:

```text
dist/RasterLab3.exe
```
