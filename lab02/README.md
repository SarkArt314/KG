# Лабораторная работа 2 — вариант 8

Приложение реализует ровно два метода глобальной пороговой обработки (Otsu и
средний порог) и ровно два высокочастотных фильтра (Unsharp Mask и Laplacian).

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

В меню **Файл** можно открыть изображение и сохранить последний результат.
Предпросмотры автоматически подстраиваются под размеры панелей при изменении
размера окна. Результаты Otsu и среднего порога можно сохранить отдельно;
процент различающихся пикселей отображается в метриках.

## сборка

```powershell
build_exe.bat
```

PyInstaller помещает исполняемый файл в `dist\Lab2_ImageProcessing.exe`.
